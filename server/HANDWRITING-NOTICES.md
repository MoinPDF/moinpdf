# German handwriting recognition

Offline single-line inference using naeyn/de-htr-web-v2, revision 6241c1ff0fd42725e0dc46fcd3217469cac851bb. Apache-2.0 model/software terms and the publisher training-data notice are installed alongside the model. Sources and checksums: handwriting.lock.json.

Modern German handwriting only. Recognition requires correction against the original. No accuracy guarantee, historical-script support or whole-page recognition is claimed. No runtime model download or external API.

Public integration fixture: FH Südwestfalen German Handwriting dataset (AFL-3.0). It belongs to a training source and does not measure accuracy on unseen writers.
