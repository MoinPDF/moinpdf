# Security

[Deutsch](SECURITY.md) · **English** · [← README](README.en.md)

## Report a vulnerability

Please report security issues confidentially to **[post@moinpdf.de](mailto:post@moinpdf.de)**. Do not post credentials, real documents or exploit details in public issues.

Include the MoinPDF version, affected tool, reproducible steps using synthetic data and the observed impact. General questions and feedback belong at **[ahoi@moinpdf.de](mailto:ahoi@moinpdf.de)**.

## Supported versions

Security fixes are intended for the current release. There is no guarantee of fixes for older versions or of a specific response time.

## Operation and verification

- Use synthetic documents when testing.
- Protect publicly reachable installations as described in [DOCKER.en.md](DOCKER.en.md).
- Keep document contents and credentials out of logs and test artifacts.
- Use pinned container and model versions and update them deliberately.

Automated checks reduce the risk of errors but do not replace a complete assessment of the actual installation.
