2. Documents and local processing

When you select files or drag them to the homepage, MoinPDF first reads them in your browser. The document contents, file names, metadata and your editing inputs selected by you are processed. This may include personal and confidential information.

Browser tools such as joining, sharing, rotating, text recognition, image editing and creating export files work on your device. These features do not upload your documents to a document server or an AI service. The required program libraries, fonts and OCR language files are provided together with MoinPDF.

Opened files, previews, editing steps and results are stored in memory during the session. Without project storage, the work session ends when reloading or closing. Through "projects" you can permanently store documents and edits locally in this browser; When opening another project status, the current session is also secured locally beforehand. Original files and downloaded results on your device will remain regardless. Local storage is described in Section 5.

The selection of documents and the use of the tools are voluntary. Without a suitable file, the tool in question cannot work. If you use other people’s documents, you must be entitled to processing and ensure the necessary legal basis.

3. Document servers and translations

Certain tools require a document server, such as Office conversions, PDF/A, full invoice checks, and certificate signatures. In the complete Docker installation, this server is integrated. The connection is automatic. Users do not need to enter a server address or access key. In an output without an integrated document service, only the local functions offered there are available. Checking the connection does not transmit document files.

Only when you start the processing with the respective action button, the app sends the selected file and the required settings to this server. Depending on the tool, this also includes invoice XML, e-mail attachments, Word templates or Excel tables. When signing, the selected certificate including the contained private key and the entered certificate password for the signature job are transmitted.

For orders over the access secured with Cloudflare, the transmitted documents, settings and results are also routed through Cloudflare’s infrastructure. Further details are given in Section 4. Local editing in the browser does not trigger this transmission.

For PDF translations, the document server forwards the read text to the configured translation service. The complete Docker installation uses its own LibreTranslate service in the internal network. The tool view offers the supported source and target languages.

The supplied server uses order-related temporary working directories and removes them after the end of processing even in the case of regularly handled errors. He does not keep permanent document storage. The Docker volumes contain operational data such as language models and internal keys, not intended document archives. The cancellation of the waiting in the browser does not necessarily end an already started server order immediately.

The technical processing serves exclusively the order you started. As far as own personal user data is necessary for the provision of the requested service, art. 6 par. 1 lit. b GDPR the legal basis. In the case of documents of other persons, the roles and legal bases depend on the respective use; a release in the interface does not replace its legal basis or any necessary agreement for order processing.

For independently operated document or translation servers, the information of their operators also applies. Their actual storage and sharing cannot be controlled by this web app.

4. Website access, hosting and registration

When the website is accessed, technically necessary connection data are processed, in particular IP address, time, requested address and technical browser information. This is different from the locally opened documents. The purpose is the delivery of the app, troubleshooting and protection against misuse. The legal basis is Art. 6 para. 1 lit. f GDPR; the legitimate interest is in safe and functional operation.

Own server

The self-hosted version of MoinPDF is operated on a separate server of the controller. There, the web app, the document server and the translation service included in Docker run. In the supplied document server, HTTP access protocols are deactivated; The provided web proxy does not activate its own HTTP access protocol. Technical operating and error messages can nevertheless arise. For their necessary storage period, the correction of a fault, the clarification of a security incident and, if necessary, legal storage obligations are decisive.

If password protection is activated, the login is checked by the web server. The browser can keep the access data for the session. Document requests are not made publicly available as an archive.

Cloudflares

Cloudflare is connected upstream of its own server for the delivery and security of the website. The provider is Cloudflare, Inc., 101 Townsend Street, San Francisco, CA 94107, USA. Cloudflare processes in particular IP addresses, connection and request data as well as security information in order to forward requests and to detect attacks or abuse. The use is based on art. 6 par. 1 lit. f GDPR and the interest in a reliable, secure provision.

As an intermediate service, Cloudflare also processes the contents of the requests and answers transmitted via this access. For server tools, this concerns the data described in Section 3. HTTPS protects transport; However, Cloudflare is part of the processing chain and can access the decrypted content when switching. For the processing of the contents of the contract, the purposes and legal bases set out in Section 3 apply.

Through Cloudflare’s worldwide network, processing can take place outside the EU or the EEA, in particular in the USA. Cloudflare identifies the EU-US Data Privacy Framework for collected US transfers and EU standard contractual clauses with additional protections for other limited third-country transfers. The conditions and guarantees provided are in Data Processing Addendum described.

The retention of connection and security data depends on the service, its settings and the processing purpose. Cloudflare cites in particular the necessity for the service and its security as well as legal obligations as criteria. The end of a document job therefore does not automatically delete all connection data at Cloudflare. Additional information shall include: Cloudflare privacy policy; Information about security cookies is provided in Section 5.

5. Browser storage, cookies and analysis

MoinPDF does not contain any built-in advertising or analytics trackers. The interface does not require permanent own cookies. Technically necessary cookies of an upstream registration or hosting service must be distinguished from this.

Depending on the protection functions enabled, Cloudflare can set security cookies, such as “ cf bm” for bot recognition or “cf clearance” to remember a passed security check. ‘ cf bm’ expires after 30 minutes without activity; the validity of cf clearance depends on the configured protection function. As far as access is absolutely necessary for the secure provision, it takes place on the basis of § 25 Abs. 2 No. 2 TDDDG; the processing of personal security data is based on art. 6 par. 1 lit. f GDPR. Local PDF projects
Document files, file names, page arrangement, editor changes, forms, bookmarks and undo history stored via "projects" are stored unencrypted in IndexedDB under "moinpdf.projects.v1". This also applies to previously unlocked PDFs. The last five stored working positions are recoverable. A selected stand can be saved as a .moinpdf project file on your device and opened in another browser. This file contains originals, edits and unencrypted undo history. When opening another project status, the current session is secured locally before the change. There is no upload. Projects are retained until deletion in the app or removal of website data; The browser can also remove data in the event of a lack of memory.
Stored workflows
If you explicitly select “Save Expiry”, the browser saves the name, the work steps and their settings in the localStorage under “moinpdf.workflows.v1”. This can include self-entered stamp or watermark texts. Document files and opening passwords are not stored. The entries remain until the expiration or deletion of the website data.
Connection and certificate password
The interface does not store any server address or API keys. A possibly existing entry "moinpdf.document-server" from older versions is no longer used and can be deleted via the website data. Certificate passwords remain in memory for the current signature job and are removed from the input field after completion.
Optionally stored assistant model
If you activate “Save model file for later sessions on this device” in the local assistant, only the tested model file is saved in IndexedDB under “moinpdf.local-model.v1”. Document content, questions and answers are not stored there. Using “Unload model and delete saved copy” or removing the website data, you can delete the model file again. Without this selection, the model remains in memory only for current use.
Program and language files
The browser can cache program files and OCR language models in IndexedDB. As a result, they do not have to be loaded again every time they are recognized. These caches do not contain any document files stored there by the app. They can be deleted via the browser settings for the website data.

These memory accesses serve the expressly desired functions. As far as they are absolutely necessary for this, § 25 Abs. 2 No. 2 TDDDG. Personal settings are used to provide the requested function based on type. 6 par. 1 lit. b GDPR processed. Unnecessary analytics or advertising accesses are not triggered by MoinPDF.

6. Photo selection and optional assistants

The camera scanner uses the photo or file selection of your device. A supported browser can offer the camera. The selected images are first edited locally; The app does not start a permanent camera stream. The operating system and browser control the necessary permissions.

The local document assistant uses the Qwen2.5 0.5B Instruct language model on your device. The selected document texts, your question and the generated answer are processed locally and are not transmitted by this function to a model provider. Questions and answers remain in the open session unless you specifically export them as a file. Via “Unload model and delete saved copy” you can end the model runtime.

The model file is not automatically loaded by a third party. The offered download link opens Hugging Face, Inc. as an external service; You then select the downloaded file yourself. When called up and downloaded, this provider receives technically necessary connection data such as your IP address as well as browser and device information. According to his data protection declaration, processing in the USA is also possible. Documents and questions are not attached to the download. Details are given in the Privacy Policy of Hugging Face. An existing suitable model file can be selected without another external download.

If you use a compatible browser assistant, it can use the interface provided to query file names, page numbers, selected pages, the number of edits and the processing status, and select the tool and page area. This interface does not provide document content. What an assistant you use can also perceive or process in the browser depends on its permissions, providers and settings.

8. Your rights

Within the legal scope, you have rights to access, rectification, deletion, restriction of processing and data portability. You can revoke a given consent at any time for the future; the lawfulness of the previous processing remains unaffected.

Objection: Against processing on the basis of art. 6 par. 1 lit. f DSGVO you can object for reasons of your special situation. Then turn to it. post@moinpdf.de.

You can complain to a data protection supervisory authority, especially at your whereabouts, workplace or where a suspected breach occurs. For the operator in Lower Saxony, State Commissioner for Data Protection in Lower Saxony a point of contact.

MoinPDF does not make automated decisions with legal or similar significant effect and does not create user profiles. Technical document checks and translations are tool results and do not replace your own check.
