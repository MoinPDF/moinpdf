01

In a few steps

Your first document

MoinPDF first opens your documents in a shared workspace. You then decide what to do with them. Your files on the device are not overwritten.

Use Customize to choose and reorder up to six favorites. Recently used tools and a shortcut to existing workflows appear below. Categories show all their tools; All tools opens the complete catalogue.

On mobile, Home, Tools, Search, Projects and More appear along the bottom. The magnifying glass opens direct tool search; the close button dismisses it. Projects also opens from the bottom navigation. On desktop, Search tools or Ctrl/Cmd+K opens global search, including while editing. Tools opens the complete catalogue.

  1. 1

    Open files

    Drag PDFs, invoice XML or supported image files such as JPG and PNG into the upload area, or choose “Select files”. You can open several files together. An Office file, email, HTML file or EPUB opens the appropriate converter directly.

  2. 2

    Choose what to do

    Use tool search to describe your goal, such as “Make a PDF smaller” or “Text from a scan”. Choose a search suggestion, a category or a tool. “All tools” opens the overview even without a file.

  3. 3

    Check, apply, download

    Configure the tool and check the preview and page selection. Start processing with the action button. Download the result or choose “Keep editing” to use a generated PDF for the next step.

Remember to save your result.

The workspace is saved locally for recovery. The latest ten results remain in the tray up to 160 MB in total. Projects lets you save up to five named snapshots and transfer them as .moinpdf files. Local data is unencrypted; project files can optionally be password-encrypted. Browsers may remove local data when space is low. Download important results as well. Clearing the workspace removes its recovery snapshot and result tray. Backups from other tabs and documents remain available and can be discarded individually.

02

Orientation

Your workspace

Write a new document

“New document”, in the top bar, opens the document editor without uploading a file. Write on the blank page, format text and insert local images, tables or page breaks. Under “Page”, set the paper format, orientation, margins, headers, footers and page numbers.

The editing view adapts to the space available on your phone. “Page preview” shows the actual PDF pages, including automatic page breaks. Check this view before choosing “Download as PDF”.

The editor automatically saves drafts locally in this browser. Under “Drafts”, open saved documents, create a blank document, or download and reopen an editable .moindoc file. Document drafts and PDF projects are separate workspaces. Clearing browser data removes local drafts; download important documents as a backup.

Everyday file and result controls

Returning from a tool restores the category, search query and scroll position of the previous selection. Search also understands everyday phrases such as “take a page out” or “too big to email”.

For identical uploads, you can skip the duplicate or add it anyway. Files are compared by content; files with the same name but different content still open. You can remember your choice for further duplicates in the same upload.

Click the filename beside the download button to edit it. The extension continues to match the output format. Enter confirms the change; Escape cancels it. The result summary shows the format, size and, for PDFs, the known page count. Compression and optimization also show the size change where a comparison is meaningful.

Share opens your device’s file-sharing dialog when the browser supports the result format. Choose the desired app yourself. Cancelling leaves the result open. If file sharing is unavailable, you can download the file as usual.

Change tool

Use “Change tool”, “All tools”, or “Back” on mobile to return to the tool selection. Your open files are retained. Search and categories help you switch between Check, Convert, Pages, Edit and Batch.

Select pages

Many standard tools only process selected pages in their current order. Check the “… of … pages selected” count. Unselected pages are omitted from this output; the original file is kept.

Preview and settings

Use “Pages” to reorder and rotate pages. “Preview” shows an individual page for placing areas and content. The tool sidebar starts collapsed and can be opened with “Show toolbar”. On smaller screens, settings appear below the preview.

Complete documents

Form, bookmark and many advanced tools work with complete documents. When switching tools, MoinPDF applies pending page and region changes along with form and bookmark drafts. Review any prompt about possible loss of PDF structures and select the correct document when several files are open.

Your open files

After opening files, the document summary shows file names, the page count and total size. Expand the list to see the names of multiple files. Use the plus icon to add files where the current workspace supports it.

Actions on your phone

The PDF editor provides Tools, Undo, Format and PDF output along the bottom. Format opens the settings from below; drafts are retained when it closes. Other shared PDF tools keep their action bar at the bottom: Back returns to tool selection and the action button starts processing. You can cancel an active task. Once its result is open, the bar offers the download. Standalone converters retain their own action buttons.

Combine editing steps effectively

When switching to a document or specialist tool, MoinPDF adopts the current workspace. Unchanged files remain unchanged; possible losses of forms, attachments or other structures are explained before adoption. Continue editing result also creates an undoable workspace state. A direct shortcut appears at the top whenever results or jobs exist. More → Results and jobs remains available. After generating a PDF, you can directly edit text, switch to Word, compress it or save a project.

Apply visual edits such as redactions or replacement text before rotating pages afterwards. Apply password protection and certificate signatures at the end of editing.

Undo and keyboard shortcuts

Ctrl / ⌘ + Z
Undo the last page or area change.
Ctrl / ⌘ + Shift + Z
Redo the undone change.

The history keeps up to 30 working states, including page and region changes and adopted results. Adding or closing files starts a new history. For large documents, the storage limit may remove older states sooner. Not every setting in a standalone tool is part of this history.

Good to know

Where your files are processed

The label in each tool guide indicates where processing is intended to take place. The availability of server-based features depends on the MoinPDF edition you use.

Browser
These tools process document content on your device. This includes local OCR, many checking tools and page design. Simply opening a document does not upload it to the document server.
Document server
The service is integrated in the full MoinPDF installation. The action button transfers the selected input to that installation’s server. You do not need to enter a server address or API key manually in the interface.
Browser / server
Office to PDF and certificate signatures offer local processing and an explicitly selected server mode. PDF to Word offers local page-layout output and flowing text with tables and images; the document server provides another converter. Compress PDF to target size runs locally or on the document server. Each guide describes its requirements and limitations.

The browser-only edition may show tools whose processing requires an available document server. In the audiobook tool, the text to be read aloud can also be saved as TXT without generating audio. If a feature is unavailable, read the note in the tool.

Session, settings and temporary jobs

The workspace and latest results are automatically stored locally for recovery. Saved projects contain the open documents and snapshots unencrypted in IndexedDB. Opening another snapshot first saves the current session. Project files are exported and imported without uploading. Import creates a separate project; data, sizes, checksums and page references are validated. A snapshot includes its undo history; a complete archive contains up to five saved snapshots. Export review lists included originals and earlier steps. Optional password protection encrypts the exported file, not browser storage. An encrypted file cannot be recovered without its password. Projects can be deleted in the app or by clearing site data. Saved workflows contain only steps and settings, not documents or passwords. Projects shows estimated storage usage and persistence status and lets you request persistent storage. Keep a downloaded backup as well.

The document server stores supported background jobs and results for up to 24 hours; inputs are removed when processing completes or is cancelled. Cancelling a background job terminates its converter processes. For synchronous calls, stopping the browser request does not necessarily stop processing immediately; audio jobs have a three-minute timeout. Certificate, private key and password are sent only in the server signing mode. Local signing keeps them on your device.

Prepare for offline use

Open Projects, then Manage offline packages. Choose the required languages and optionally the Office converter. Download / update selection verifies program files before saving them. HTTPS or localhost and a supported browser are required. Keep the app open during the download. An update activates once all older MoinPDF tabs have closed. You can install the app from the browser menu.

Remove offline files deletes saved program packages only. Projects and results remain available. Documents and API responses are not stored in the offline cache. Server tools still need a connection to your document server. An online sign-in wall is not bypassed by the offline copy.

Verify and share exports

Shared export verification checks PDF readability and known page counts. When source-page mapping is available, it compares dimensions, links and form fields; tools that preserve text also compare original text. Changes or verification gaps must be acknowledged before downloading. Verification is limited to 200 pages and 100,000 characters per page. Password-protected output is labelled as not content-verified. This is not a complete visual comparison or a guarantee of content accuracy.

Flattened PDF for sharing exports only the visible pages of the latest selected project snapshot as page images up to 2800 pixels. Source files, attachments and edit history are omitted. Searchable text, links, interactive forms and certificate signatures are not retained. Visible confidential information remains visible; review the PDF before sharing.

Translation and speech output

The first complete installation downloads translation models for the offered languages and needs internet access. Translation then processes text on your own server. German Piper voices Thorsten and Kerstin and LJ for US English are installed and generate audio there without a cloud service. OCR processes documents on your device. Available languages and combination limits are listed under Current implementation limits; an optional local sample can suggest suitable languages.

Information about the operation of this website and data protection can be found in the Privacy policy. For a self-hosted installation, the information provided by its operator also applies.

When something goes wrong

Questions & troubleshooting

The processing button is greyed out. What is missing?

Check the file and page selection, required inputs and previews still being generated. Some tools need two files. For outputs that require review, you must first explicitly confirm matches, dates or the text to be read aloud. Server features also need a document server that is ready.

My changes are missing in the next tool.

When switching tools, MoinPDF applies pending changes from the shared PDF workspace. Adopt a separately generated result with “Keep editing” or from the results tray. If prompted, review and confirm possible loss of PDF structures. Check the selected source when several files are open.

The search does not find words in the scan.

A scan starts as an image. Run text recognition in the page finder or create a searchable PDF with “OCR & text”. Use the result as the source for other tools. For rotated or blurry pages, improve the orientation and scan quality first.

The compressed file is still too large.

Some PDFs are already well compressed. Check the reported file size after compression. Image compression can help, but reduces quality. “Split by file size” is an alternative; a single oversized page must first be reduced.

A form cannot be filled in.

It may contain only printed lines or a page image. Add real form fields with “Create form” or detect suggested fields automatically. Dynamic XFA forms are not fully supported. Also test the finished file in the PDF application that will be used later.

The document server or translation is not ready.

Not all server functions are available in the browser-only edition. If you host MoinPDF yourself, check that all services have started. On first launch, translation models can take several minutes to load. You can use other browser tools in the meantime. Then try the affected function again.

Processing is taking a long time or has been cancelled.

Large scans, OCR and audio take time. Keep the app open for local processing. After uploading, supported server conversions can continue with “Continue in background”; reopen them under “More → Results and jobs”, including after a page reload. Check for an existing job there before starting it again. Jobs and results are deleted no later than 24 hours after creation; “Cancel” stops processing. Other server features and upstream tunnels may have their own time limits.

The camera does not open.

Check your browser’s camera permission and use HTTPS. Plain HTTP over a local IP address often does not allow camera access. Alternatively, select an existing photo and correct its perspective in the camera scanner.

Why is my OCR correction not visible on the PDF page?

OCR corrections change the invisible search layer, not the visible scan image. Choose “Apply corrections” and download the updated PDF. Search it for the corrected word. To change the visible letters too, use “Edit PDF”.

After exporting, I can no longer select text.

The tool probably created page images. This is expected when flattening, redacting or applying scan filters, for example. Use OCR to create a new text layer if needed. After redaction, check the output again before sharing it.

The PDF preview cannot open my file.

Check the file size, page count and any required password. For damaged files, open “Repair PDF” from the tool overview and select the file there directly. A repair attempt cannot restore missing content.

Where can I find the downloaded file?

MoinPDF uses your browser’s download function. Check its download list or your device’s Downloads folder. ZIP files must be extracted first. A result that is only visible in the preview may not have been saved yet.

How do I report a problem clearly?

Note the tool name, MoinPDF version, browser, file type, approximate size and exact error message. A small sample document with dummy content helps narrow down the problem.
