01

In a few steps

Your first document

MoinPDF first opens your documents in a common workspace. Then you decide what to do with it. Your files on the device are not overwritten.

  1. 1

    Open files

    Drag PDFs, Invoice XML, JPGs or PNGs onto the animated document or use the file selection. You can open several files together. An Office file, email, HTML file or EPUB directly opens the appropriate converter.

  2. 2

    Selection of projects

    Under “What do you want to do?” you describe your goal, for example “Make PDF smaller” or “Text from Scan”. Choose a search suggestion, a category or a tool directly. “All tools” opens the overview even without a file.

  3. 3

    Check, apply, download

    Set the tool and control preview and page selection. Start the processing via the action button. Download the result or take a generated PDF with “Continue editing the result” for the next step.

Securing the result in time.

Documents and changes are stored in the memory of the current session. Via "Projects" you can store files and edits with up to five workstations locally in this browser. Unstored changes can be lost when reloading or closing. With “Download Project File”, the current or stored status can be continued as a .moinpdf file on another browser. This file contains originals and the undo history unencrypted. Use the result PDF to pass on finished documents. The documentation opens from the app in its own tab.

02

Orientation

Your workspace

Change tool

With “Change tools” or “All tools” you come back to the selection. Opened files are retained. Search and categories help you between Testing, converting, pages, editing and stacking to change.

Selecting Pages

Many classic tools only process selected pages in the current order. Check the indication ‘... selected from ... pages’. De-selected pages are missing from this edition; the original file remains.

Preview and settings

In the page overview, you sort and rotate pages. The document view shows a single page for placing areas and content. On smaller screens, settings are partly previewed; the tool strip can be folded in.

Complete documents

Form, bookmark and many advanced tools work with the full source files. Choose the correct document there. Changes not yet applied from another tool are not automatically part of this source.

Connecting processing sensibly

Apply one work step first. Check the generated PDF and select “Continue editing the result” before using the next tool. This makes the new PDF a working document. The previous composition and the undo course are replaced; safe required intermediates beforehand.

Apply visual edits such as redaction or replacement texts before a subsequent rotation. Password protection and certificate signature belong to the end of the processing.

Undo and keyboard shortcuts

Ctr / ⌘ + Z
Take back last page or area change.
Ctr / ⌘ + Switching + Z
Repeat the withdrawn amendment.

The course includes up to 30 page and area changes. When adding or closing files, it starts again. Not every setting of an independent tool belongs to this process.

05

Good to know

Where your files are processed

The marking of each tool manual shows which processing is intended. The availability of server-based features depends on which MoinPDF output you use.

Browsers
These tools process document content on your device. This also includes local OCR, many test tools and page design. Merely opening a document does not upload to the document server.
Document servers
The full MoinPDF installation integrates the service. With the action button, you transfer the selected input to the server of this installation. The interface does not require a manual server address or an API key.
Browser / Server
“PDF to Word” and “Compress PDF on desired size” offer a more limited local path in the browser output. The complete installation complements layout conversion or image reduction. The respective instructions describe the difference.

Pure browser output can display tools whose processing requires an available document server. In the audiobook, the audible text can also be stored as TXT without audio generation. If a function is not available, note the note in the tool.

Session, settings and temporary orders

Without project storage, documents and edits remain in the memory of the session. Deliberately stored projects contain the open documents and work statuses unencrypted in IndexedDB. When opening another project status, the current session is secured locally beforehand. Project files can be exported and imported without upload. When importing, a separate project is created; Data, sizes, checksum and page references are checked. The file contains the selected status and undo history, not all five separately stored statuses. Projects can be deleted in the app; Deleting the website data also removes them. Saved workflows contain only steps and settings, no documents or passwords. Program data and language packets can be cached in the browser.

The document server uses temporary order files and removes them at the end of processing. Aborted retrieval does not necessarily immediately stop an already started server process; an audio order ends at the latest after its three-minute time limit. Under "Certificate Signatures", certificate, private key and password are also transmitted for signing.

Translation and translation services

At the first full installation, the translation models for the languages offered are loaded; This requires Internet access. After that, the translation processes texts on its own server. The two German Piper voices are installed and generate audio there without a cloud service. OCR uses supplied German and English language data on your device.

Information about the operation of this website and data protection can be found in the Privacy policy. In the case of a self-operated installation, the information of its operator is also decisive.

When something gets stuck

Questions and error help

The processing button is greyed out. What is missing?

Check file and page selection, required input and ongoing previews. Some tools need two files. For expenditures in need of control, you must first explicitly confirm hits, dates or aloud text. Server functions also require a ready document server.

My changes are missing in the next tool.

Apply the first step and select “Continue editing the result”. Many stand-alone tools read the full source and not the as yet unsaved changes of another workplace. For multiple files, look for the selected source.

The search does not find words in the scan.

A scan is initially an image. Start the text recognition in the page finder or create a searchable PDF with "OCR & Text". Take over the result for other tools. In the case of twisted or fuzzy pages, alignment and scanning quality are initially improved.

The compressed file is still too large.

Some PDFs are already well compressed. Check the indication of the actual size achieved. Image compression can help, but it costs quality. “Share by file size” is an alternative; A single too large page must first be reduced.

A form cannot be filled in.

It may contain only printed lines or a page image. Create real fields with “Create form” or let field suggestions be recognized. Dynamic XFA forms are not fully supported. Test the finished file also in the PDF program that will be used later.

The document server or translation is not ready.

In the pure browser output, not all server functions are available. If you run MoinPDF yourself, check that all services have started. At the first start, the translation models can take several minutes to load. You can use other browser tools during this time. Then try the affected function again.

Processing takes a long time or has been terminated.

Large scans, OCR and audio require computing time. Keep the app open, divide long documents into smaller orders and check the progress indicator. After a connection error, you can start again with a smaller input. Additional time limits may apply via an upstream tunnel. Reload only when the required results are secured.

The camera does not open.

Check the camera permission of the browser and use HTTPS. Ordinary HTTP over a local IP address is often not enough for camera access. Alternatively, you can select an already taken photo and correct it in the camera scanner.

After export I can no longer mark text.

The tool used probably produced page images. This is provided, for example, for fixing, redaction and scanning filters. Create a new text layer with OCR if necessary. After redaction, check the output again before you pass it on.

The PDF preview cannot open my file.

Check size, number of pages and any password you may need. For damaged files, open “Repair PDF” from the tool overview and select the file directly there. A repair attempt cannot restore missing content.

Where can I find the downloaded file?

MoinPDF uses the download function of your browser. Check their download list or the download folder of your device. You have to unpack ZIP files first. If a result is only visible in the preview, it has not necessarily been saved yet.

How do I report a problem traceably?

Note tool name, MoinPDF version, browser, file type, approximate size and the exact error text. A small artificial example document helps with the delimitation. Write to us ahoi@moinpdf.de. Further contact information can be found in Legal notice. Do not send original confidential files or access data.
